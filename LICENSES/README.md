# Лицензии

Здесь лежат тексты лицензий данных, из которых собраны пакеты (их добавляет мейнтейнер).
Какие источники и под какими лицензиями использованы в каждом пакете, перечислено в
[`../ATTRIBUTION.md`](../ATTRIBUTION.md); каждый `.lens` также несёт свою строку атрибуции,
которую показывает устройство.

Ожидаемые файлы:

| Файл | Для чего |
|---|---|
| `CC-BY-SA-3.0.txt` | WikDict (DBnary / Wiktionary): глоссы большинства пакетов Readest и производного en-uk |
| `CC-BY-SA-4.0.txt` | Wiktionary через kaikki.org (en-vi, en-hu, en-ar), FrequencyWords (ранги), пакеты ua-dict |
| `MIT-ECDICT.txt` | ECDICT (en-zh, en-en: глоссы, ранги, словоформы) |
| `WordNet-3.0.txt` | WordNet (синонимы и гиперонимы en-en) |
| `lemmatization-lists.txt` | michmech/lemmatization-lists (словоформы исходных языков) |
| `GPL-*.txt` и разрешения авторов | словари из пакетов ua-dict (Mueller 7, slovnyk.org.ua), если такие пакеты импортированы |

Лицензию на код в `scripts/` и `tests/` (прошивка CrossLingua — MIT) мейнтейнер тоже добавляет
сюда или в корень репозитория.
